Study path

What to learn first

01

Networking fundamentals

IP addressing, CIDR, subnet design, routing, NAT, private/public access, and Google Cloud networking concepts.

02

VPC and connectivity

VPC design, shared VPC, firewall rules, service networking, peering, and interconnects.

03

Hybrid networking

VPN, Cloud Interconnect, NCC, private connectivity, and deciding when to use each pattern.

04

Load balancing and DNS

HTTP(S), TCP/UDP balancing, global vs regional, health checks, CDN, and DNS architecture.

05

Security and operations

IAP, firewall best practices, identity boundaries, logging, monitoring, and incident troubleshooting.

06

Hands-on practice

Use labs and timed simulation tests to validate traffic flow, architecture decisions, and resilience planning.

Quick recall

Exam checklist by topic

VPCOne global network; subnets are regional.
CIDRKeep ranges non-overlapping and deliberate.
RoutingMatch route behavior to traffic source and destination.
FirewallIngress default deny; explicit allow rules control access.
HybridVPN for flexibility, Interconnect for scale and performance.
Cloud RouterDynamic route exchange via BGP.
LBChoose by protocol, exposure, and backend design.
DNSPrivate DNS for internal services; public DNS for internet reachability.
SecurityLayer policy at edge, VPC boundary, and service perimeter.
MonitoringValidate routing, latency, reachability, and health before changing scope.
